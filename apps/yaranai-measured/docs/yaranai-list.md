# yaranai-list.md — あえてやらないことリスト

Yaranaiが意図的に「やらない」と決めたことの記録。
各項目は「永久にやらない」ではなく、**再検討条件が満たされたときだけ開け直す**。
条件が来ていないのに開け直す議論が始まったら、このファイルを根拠に一度止めること。

書式: やらないこと / 決定日と背景 / 理由 / 再検討条件

---

## 1. 10代(高校生・大学生)向けの獲得・訴求

- **決定日と背景**: 2026-07-29。ペルソナ再点検の際、「時間を持て余し将来が漠然と不安な10代に苔の庭は刺さらないのでは」という問いから議論。
- **理由**:
  - コアバリュー「消えない蓄積」は、何度も挑戦と失敗を繰り返した**再挑戦者**にしか価値が立たない。10代はまだ失敗の蓄積が構造的に少なく、再挑戦者ペルソナになりえない。
  - 静けさを報酬として受け取る感性は、疲弊や喪失の経験を経て育つ。庭のトーンは若年層向けのドーパミン的報酬と本質的に相容れない。
  - 実務面でも届かない: 測定版はAndroid限定(日本の若年層はiPhone比率が高い)、¥2,900買い切りは学生には重い。
- **想定コアペルソナ(参考)**: 28〜40歳、社会人5年目以降。転職活動・資格試験・婚活等を中途半端に繰り返し、スマホロック系アプリの導入と削除を経験している再挑戦者。
- **再検討条件**: マルチ庭園設計で庭スタイルの幅を広げるとき / iOS版展開で母集団が変わるとき。ただしその場合も「庭を若年層に寄せる」ではなく「別スタイルの庭を追加する」形でのみ検討する。

## 9. 初期リリースでのマルチ庭園

## 10. 流れ先アプリへの乗り換え問いかけ

- **決定日と背景**: 2026-08-01。卒業機能の設計時。誓い対象を断つと使用時間が計測外アプリへ流れる現象(ドッグフードで YouTube → Chrome への移行を確認)への対応として、「計測対象をこちらに変えませんか」という能動的な問いかけをYaranai側から行う案が出たが、見送り。
- **理由**: 五原則1「選ばせない、煽らない、通知しない」。また、流れ先が誓い対象より依存性の低いアプリ(端のあるコンテンツ)である間は、行動としてはむしろ改善であり、介入する理由がない。移し替え先は時間の行き先に自然に浮上し、ユーザー自身が次の誓いの的にできる(卒業機能がその受け皿)。
- **再検討条件**: より依存性の高いアプリへの移行が実ユーザーで多く観測されたとき。その場合もプッシュ通知は不可とし、観測画面(時間の行き先)への静的な表示の範囲でのみ検討する。

## 運用ルール

1. 新しく「やらない」を決めたら、このファイルに追記してからスペックに反映する。
2. 「やらないこと」を覆す提案が出たら、まず該当項目の再検討条件を確認する。条件未達なら議論を持ち越す。
3. 再検討条件が「なし」の項目は哲学の根幹であり、覆す場合はプロダクトの定義自体を変える意思決定として扱う。
