起動演出 — 竹林の中へ（視線3構図）

見上げから、林の中に立つ目線へ。3案とも文字を第一の焦点として設計：文字の位置に画面で最も明るい光を置き、背後に薄い影の暈を敷いて可読性を保証、周囲の竹は文字の余白を空けて配置。完全な黒250ms→夜明け、尺2.0秒はv2を踏襲。生成シード84210。

文字優先の設計：①最も明るい光（gCore）を文字位置に重ねる ②文字背後に影の暈（radial rgba(22,28,18,.34)）を1.0sで敷く ③竹の配置ロジックが文字周辺の帯を避ける（案2は靄の帯、案1・3は開口部）。落ち葉は文字への集中を優先して今回は外した（復活は1レイヤー追加で可）。タイムライン：0–250ms 完全な黒 → 250–1600ms 夜明け → 300ms 中心光 → 600/820ms 側光 → 1000ms 影の暈 → 1050ms 題字 → 1300ms コピー → 2000ms 完了。
