アイコンモック v3 — 石と苔と、銘

案Eの「石に苔がむす」を核に、道の要素を落として厳かへ。四案とも Yaranai の欧文を入れとる。彩度を落とし、苔は深い緑（mossDeep / mossSkirt 系）、余白を広く、書体は Cinzel（碑文体）と Shippori Mincho の二系統で比較する。

案H — 石と銘板

暗い苔の面に一石、その下に銘。美術館のキャプションみたいに「YARANAI」を小さく letterspaced で据える。石が主、名は従。一番静かで、一番Eに近い案。

案I — 磨崖の銘

石そのものに名を刻む。画面の大半を石の面が占めて、「YARANAI」が彫り込まれとる。下から苔が這い上がって刻銘の縁に触れかけとる——時間が名前に届く絵。摩耗した石碑の厳かさ。

案J — 名に苔がむす

ワードマークそのものが石。生成りの余白に「Yaranai」を明朝で据えて、文字の足元に苔がむしとる。タイミー型の「名前＝アイコン」に一番忠実な案。文字が主役やけん、厳かさは余白と墨色で作る。

案K — 苔むすY（モノグラム＋銘）

大きなYを石として立てて、苔がむす。小サイズでは「Y」一字で識別、大サイズでは下の「YARANAI」の銘まで読める二段構え。48dp耐性とワードマークの両立を狙った、うちの本命。

厳かさの作り方（v2からの変更）：①新緑（#BCCB86 / #C6D48F）を捨てて mossDeep 系（#54673A / #46572F / #313E23）へ ②高彩度の粒を減らし、opacity を落とす ③欧文は碑文体 Cinzel（H・I・K）と明朝 Shippori Mincho（J）で比較 ④背景に暗のヴィネット、光は右上に一滴だけ。

要注意：「YARANAI」7文字は48dpでは読めん（タイミーも同じで、小サイズは形と色で識別されとる）。文字が読める前提の案（I・J）は72dp以上での見え方を主戦場に、48dpはシルエット勝負になる。書き出し時は全 text 要素を必ずパス化。backgroundColor 案：H #313E23 / I #DAD1B6 / J #F2EDE1 / K #1C2313。
